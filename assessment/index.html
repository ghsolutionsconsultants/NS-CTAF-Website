Assessment process

Six phases from scope to certification readiness

Automated tooling structures the scoring; independent assessors validate the evidence.

01

Scoping

Define systems, repositories, pipelines, products, environments, and regulatory context.

→ Assessment scope and priority domain list.

02

Evidence Collection

Collect SBOMs, CI/CD logs, signing evidence, policies, scan outputs, attestations, runtime data, and governance documents.

→ Evidence register and gap log.

03

Automated Tool Review

Use the NS-CTAF assessment tool to structure scoring, dashboards, recommendations, roadmap, and readiness.

→ Draft scorecard and preliminary roadmap.

04

Assessor Validation

Review evidence quality, test claims, apply hard scoring gates, and validate control maturity.

→ Validated maturity scores.

05

Reporting

Produce Trust Score, domain scores, control gaps, roadmap, board report, and regulatory view.

→ Final report pack.

06

Certification Readiness

Determine whether the assessed organisation qualifies for CTA-1, CTA-2, CTA-3, or CTA-4.

→ Certification recommendation.

Method principles

How we keep it rigorous

  • Evidence-first assessment, cryptographic evidence preferred
  • No maturity inflation through policy-only evidence
  • Clear scope definition before scoring begins
  • Repeatable scoring across the five NS-CTAF axes
  • Hard scoring gates cap maturity where trust conditions are absent
  • Independent review before certification is issued
Evidence tiers

Cryptographic proof beats assertion

Higher maturity levels require higher-tier evidence — there is no maturity inflation through policy-only documentation.

T1

Cryptographic evidence

Signatures, attestations, hashes, transparency-log entries, SBOMs, provenance records.

T2

System-generated artefacts

CI/CD logs, automated scan reports, pipeline execution records, monitoring dashboards.

T3

Structured documentation

Policies, standards, process documents, architecture diagrams, manual records.

T4

Management attestation

Interview responses, declarations, and unverified assertions.
